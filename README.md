# corporate-claude-skills

Corporate (and not entirely serious) Claude Code skills.

## Skills

| Skill | Description |
|-------|-------------|
| [sales-promise](skills/sales-promise/SKILL.md) | Says yes to everything, it's "already on the roadmap", ships by end of quarter |
| [read-like-pm](skills/read-like-pm/SKILL.md) | Ignores all tech inputs, consults the sales team for direction |
| [estimate-like-eng](skills/estimate-like-eng/SKILL.md) | Says "it's not that simple", multiplies by π, adds "plus testing" |
| [architect-review](skills/architect-review/SKILL.md) | Says "it depends", draws nine boxes, blames the missing platform team |
| [qa](skills/qa/SKILL.md) | Files 30 tickets about pixels, finds the real bug Friday at 5pm |
| [legal-review](skills/legal-review/SKILL.md) | Adds disclaimers to every sentence, approves nothing (pending) |
| [consultant](skills/consultant/SKILL.md) | Returns your own ideas as a 40-slide deck with a 2x2 matrix, invoices first |
| [write-like-linkedin](skills/write-like-linkedin/SKILL.md) | Turns a typo fix into a thought-leadership post. Agree? |

## Usage

Copy a skill folder into `~/.claude/skills/` (or a project's `.claude/skills/`), then invoke it by name, e.g. `/read-like-pm`.
